# M3: Z80 Emitter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan task-by-task.

**Goal:** Implement the Z80 assembler per `docs/specs/2026-05-24-m3-z80-emitter-design.md`: a SAM-side Z80 program that reads a `.tbn` file, looks up forms in the loaded `enctab.enc` table, encodes the bytes via per-slot encoders, and writes the result via SAMDOS HSAVE. End-to-end byte-matches `aarch64-none-elf-as` for the M3 fixture corpus (fully constant-folded operands).

**Architecture:** A `pyz80`-assembled Z80 binary (`src/assembler.asm` and includes) injected onto a SAM disk via `samfile`, alongside the encoder table and a `.tbn` input. Boot via M0's BASIC autorun → `LOAD CODE`/`CALL`. The emitter is single-pass (no symbol table, no PC-relative — those are M4). Per-slot encoders are direct Z80 ports of `tools/aarch64enc/`'s Go functions.

**Tech Stack:** pyz80 1.0+ (Z80 assembler), SAMDOS 2 (vendored), SimCoupé (patched, `-exitonhalt`), `aarch64-none-elf-as` for byte-diff oracle. Existing M0 infrastructure (`tools/build-disk.sh`, `tools/run-simcoupe.sh`, `tools/check-toolchain.sh`) is reused and extended.

**Reference:** §N references point at `docs/specs/2026-05-24-m3-z80-emitter-design.md`.

```asm
; M3 Z80 assembler — top-level.
; Per docs/specs/2026-05-24-m3-z80-emitter-design.md §2.1.
;
; Boot via M0's BASIC autorun pattern: CLEAR&7FFF; LOAD CODE

        org 32768

        ; M3 scaffold: halt immediately. Real loader arrives in Task 2.
```


## Task 3: Load enctab.enc into a paged region at startup

The encoder table file lives on the disk; the Z80 reads it via HGFLE+LBYT into a paged RAM region. Pick a page (default: page 6, address `0x8000` after `OUT (HMPR), A` with A=5 — actually best implemented via `out (LMPR), A` to put the page in `0x0000-0x3FFF`; consult `docs/notes/sam-paging.md`).

**Files:**
- Create: `src/loader.asm`

This task is **substantial**. The subagent should:

1. Open `enctab.enc` via HGFLE (filename = "enctab.enc", pad with spaces to 10 bytes per SAM convention; see M0's stub for the pattern).
2. Read magic "ENC1" — verify byte-by-byte. On mismatch, exit with a non-zero code.
3. Read version (u16 LE) and flags (u16 LE) — verify version=1.
4. Read form count (u32 LE), then read `form_count * (11 + slots * 4)` bytes into a paged region. The exact size depends on the number of slots per form — read each form header (11 bytes), parse `operand_count`, read that many 4-byte slot records.
5. Read mnemonic index count (u32 LE), then `count * 8` bytes.

Use M0's HGFLE + LBYT loop pattern (`src/sam_io.inc`'s `fill_uifa` for filename setup, then LBYT in a loop).

**Step 1: Failing assertion**

Before any encoding work, write a self-test: after loading, the magic must be readable at a known offset in the buffer, and the form count must be non-zero.

```asm
        ; assertion at end of init
        ld a, (buffer + 0)
        cp 'E'
        jp nz, fail
        ; ... etc for "NC1"
        ld a, (buffer + 4)
        cp 1               ; version
        jp nz, fail
        ; ... etc
```

**Step 2-N**: Implement loader as outlined above. Iterate against a real `enctab.enc` (regenerate via `make enctab` first).

**Commit**: `g commit -m "m3: load enctab.enc + validate header at startup"`

## Task 4-15: Per-slot encoder implementations

Each task implements one or two slot encoders in `src/slots/`, with:

- A Z80 subroutine matching the Go interface (`encode_<kind>`).
- A self-test block at startup that exercises the encoder with hardcoded known inputs and asserts the output matches the expected u32.
- A new fixture in `tests/m3/sources/` exercising the encoder via the full round-trip.

The Go implementations in `tools/aarch64enc/slots_*.go` are the executable spec. Each Z80 implementation must produce byte-identical output for every input.

**Tasks**:

- **Task 4**: Xreg / Wreg / XregOrSp / WregOrSp (`slots/xreg.asm`). 5-bit pack at slot.BitPosition. ~30 lines Z80.
- **Task 5**: Imm5 / Imm6 / CondCode / ShiftAmount (`slots/imm_small.asm`). N-bit unsigned pack. ~40 lines.
- **Task 6**: Imm12Shifted (`slots/imm12_shifted.asm`). add/sub imm, with sh:1 bit. ~80 lines.
- **Task 7**: Imm16Shifted (`slots/imm16_shifted.asm`). movz/movk with hw:2. ~70 lines.
- **Task 8**: ExtendOp (`slots/extend_op.asm`). option:3 + imm3:3. ~80 lines.
- **Task 9**: BranchImm26 / BranchImm19 / BranchImm14 (`slots/branch_imm.asm`). Constant-offset only: divide by 4, sign-extend to slot.BitWidth, range-check. ~150 lines (range-checks are gnarly on Z80).
- **Task 10**: AdrpImm (`slots/adrp_imm.asm`). immlo:2 at bit 29, immhi:19 at bit 5. Constant offset only. ~120 lines.
- **Task 11**: LogicalImm (`slots/logical_imm.asm`). Port of LLVM processLogicalImmediate. The hardest single subroutine in M3 — find smallest replicating element size, check single ones-run, pack (N:1, immr:6, imms:6). Probably 200-300 lines including 64-bit helpers.
- **Task 12**: BitfieldImm (`slots/bitfield_imm.asm`). BFI + UBFX (lsb,width) → (immr,imms). ~80 lines.

Each task ends with a successful round-trip for at least one fixture exercising the slot.

## Task 16: Stream reader for .tbn records

`src/reader.asm` — walks the statement stream. For each record:

- Read kind byte.
- Read len (u16 LE).
- Dispatch on kind:
  - `KindInst` (0x01): parse mnemonic_id, operand_count, operand stream; call encoder; emit 4 bytes.
  - `KindLabelDef` (0x02), `KindLocalDef` (0x03): M4 work — for M3, error out.
  - `KindDirective` (0x04): dispatch on directive_id; emit data bytes for `.byte`/`.short`/`.word`/`.quad`/`.ascii`/`.asciz`. Other directives error out.
  - `KindComment` (0x05): skip (advance pos by len).

**Commit**: `g commit -m "m3: stream reader walks .tbn records, dispatches by kind"`

## Task 18: Encoder dispatcher

Walks the matched form's slots, calls the slot's encoder subroutine via a dispatch table, ORs each slot's bits into the result word (initialised to `pattern`).

The dispatch table is a fixed-size lookup keyed on `SlotKind` byte (`0x01`–`0x25`):

```asm
slot_dispatch:
        dw encode_xreg          ; 0x01
        dw encode_wreg          ; 0x02
        ; ... etc for all slot kinds
```

**Commit**: `g commit -m "m3: encoder dispatch by SlotKind"`

## Task 19: Constant-only expression evaluator

`src/expr_eval.asm` — postfix bytecode evaluator. Implements:

- `PUSH_IMM8` / `PUSH_IMM16` / `PUSH_IMM32` / `PUSH_IMM64`: push to a fixed stack buffer.
- `ADD` / `SUB`: pop 2, push result. (64-bit math via `ml.asm`.)
- `SHL` / `SHR`: pop 2, push result.
- `AND` / `OR` / `XOR` / `NEG` / `NOT`: ditto.
- `MUL` / `DIV`: error out (M3 doesn't implement them — the spec says text2bin should have constant-folded these).
- Any of `PUSH_SYM`, `PUSH_LOCAL`, `PUSH_PC`, `REL_*`: error out (M4 territory).

`src/ml.asm` — 64-bit add/sub/shift helpers. ~150 lines.

**Commit**: `g commit -m "m3: constant-only expression evaluator + 64-bit math lib"`

## Task 21: `tools/build-m3-disk.sh` and `tools/run-m3-roundtrip.sh`

Extension of M0's `tools/build-disk.sh` to add `enctab.enc` and the fixture's `.tbn` to the test disk alongside `samdos2`, `assembler.bin`, and the BASIC autorun.

`tools/run-m3-roundtrip.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail
src="$1"
base=$(basename "$src" .s)

# Build inputs
go run ./tools/text2bin "$src" -o "build/$base.tbn"
go run ./tools/enctab-gen -mra reference/arm-mra -gopkg tools/aarch64enc/data.go -out build/enctab.enc

# Build disk
./tools/build-m3-disk.sh build/assembler.bin build/enctab.enc "build/$base.tbn" "build/$base-disk.mgt"

# Run SimCoupé
./tools/run-simcoupe.sh "build/$base-disk.mgt"

# Extract OUT
samfile extract -i "build/$base-disk.mgt" -f OUT -o "build/$base.ours.bin"

# Reference
aarch64-none-elf-as "$src" -o "build/$base.o"
aarch64-none-elf-objcopy -O binary "build/$base.o" "build/$base.gnu.bin"

# Compare
cmp "build/$base.ours.bin" "build/$base.gnu.bin"
echo "OK: $src"
```

**Commit**: `g commit -m "m3: tools/build-m3-disk.sh + run-m3-roundtrip.sh round-trip driver"`

## What M3 explicitly does NOT include

- Symbol table / forward references / multi-pass. **M4**.
- PC-relative operators with non-constant operands. **M4**.
- Macros / `.section` / `.balign` / `.org` / `.skip` / `.equ` / conditional assembly. **M4 or later**.
- 64-bit MUL / DIV on Z80. Probably not until a real workload demands them.
- On-SAM editor. **Phase 2**.
- TFTP / networking. **Phase 3**.
