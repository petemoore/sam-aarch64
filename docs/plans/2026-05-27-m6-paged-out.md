# M6 PR 1 — paged OUT buffer implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the OUT buffer out of section C so the SAM-side assembler can emit outputs up to 32 KB (covering spectrum4 release.bin at ~22 KB). The runtime emit path uses section B during the existing LMPR_ENCTAB window — zero overhead for the first 16 KB — and an LMPR=&25 bracket for bytes 16384..32767.

**Architecture:** Per the spec at `docs/specs/2026-05-27-m6-paged-out-design.md`. OUT lives in physical pages 5 (low zone) + 6 (high zone). `emit_byte_paged` writes via section B (`&4000-&7FFF`): low-zone writes piggyback on LMPR_ENCTAB; high-zone writes bracket the store with `OUT (251), LMPR_OUT_HIGH` / `OUT (251), LMPR_ENCTAB`. End-of-pass-2 calls HSAVE per the design note at `docs/specs/2026-05-27-samdos-save-idiom.md`.

**Tech Stack:** Z80 assembly in the pyz80 dialect; SAM Coupé under SimCoupé in the `ghcr.io/petemoore/sam-aarch64-dev:latest` container (Xvfb-driven); Go-side `aarch64-linux-gnu-as` for golden generation.

### Task 2: `emit_byte_paged` + `emit_bytes_n_paged`

**Files:**
- Modify: `src/m3/encoder.asm` (replace `emit_byte` and `emit_bytes_n`)

The new emit primitive lives in the same file as the old one; the entry-point name `emit_byte` is preserved (every call site already calls `emit_byte`) — only the body changes. This way we don't touch any call site in `intercepts.asm`, `litpool.asm`, or `main_loop.asm`.

- [ ] **Step 1: Replace `emit_byte`**

The new body. ABI preserved: input A = byte; clobbers HL only; A/BC/DE preserved. Counter is `(OUT_LEN)` 16-bit. Position is `(OUT_PC)` in `&4000..&8000`. Zone tracked by `(OUT_ZONE)`.

```
emit_byte:
                push    af              ; preserve byte across LMPR/store sequence
                push    bc              ; (high zone uses BC implicitly through the LMPR save slot)
                push    de
                ld      hl, (OUT_PC)
                ld      a, (OUT_ZONE)
                or      a
                jr      nz, emit_byte_high

; ----- Low zone — write to section B with LMPR_ENCTAB live ---------------
                pop     de
                pop     bc
                pop     af              ; A = byte
                ld      (hl), a
                jr      emit_byte_advance

; ----- High zone — bracket the store with LMPR=&25 ----------------------
emit_byte_high:
                in      a, (251)
                ld      (emit_lmpr_save), a
                ld      a, LMPR_OUT_HIGH
                out     (251), a
                pop     de
                pop     bc
                pop     af              ; A = byte
                ld      (hl), a         ; write byte to section B (= page 6 under LMPR=&25)
                ld      a, (emit_lmpr_save)
                out     (251), a        ; restore LMPR_ENCTAB
                ; fall through to advance — A is dead here, free to clobber

; ----- Common tail ------------------------------------------------------
emit_byte_advance:
                inc     hl
                ld      a, h
                cp      &80
                jr      nz, emit_byte_no_zone_cross

; Hit &8000 — wrap to &4000 and flip zone.
                ld      a, (OUT_ZONE)
                or      a
                jp      nz, fail        ; already in high zone → output > 32 KB
                ld      a, 1
                ld      (OUT_ZONE), a
                ld      hl, &4000

emit_byte_no_zone_cross:
                ld      (OUT_PC), hl

; Bump 16-bit OUT_LEN.  HL is free to clobber per the original ABI.
                ld      hl, (OUT_LEN)
                inc     hl
                ld      (OUT_LEN), hl
                ret
```

Note: the `ex af, af'` pair around the LMPR restore protects whatever flag state and value `A` has from being clobbered by the `OUT (251), A` and the load of the LMPR_save value. There's no caller-observable state in A or AF, but consistency with the spec's stated "byte to emit is consumed; A is undefined after" is fine — adjust if the spec is read more strictly.

The scratch byte `emit_lmpr_save` (1 byte) is added at the bottom of `encoder.asm`:

```
; LMPR save slot for emit_byte's high-zone bracket.
emit_lmpr_save: defb    0
```

- [ ] **Step 2: Replace `emit_bytes_n`**

```
; ---------------------------------------------------------------------
; emit_bytes_n — append A bytes from (HL) to the output buffer.
;
; Input:  HL = source, A = number of bytes.
; Output: HL advanced past the source.
; Clobbers: A, BC, DE, HL.
;
; Implemented as a loop over emit_byte; the bulk fast-path that the
; M3..M5 version used (open-coded LDIR via DE = OUT_PC) doesn't work
; on the paged emit, so we eat the per-byte LMPR cost in the high zone.
; The call sites (mainly OpString) aren't on the hot path.
; ---------------------------------------------------------------------
emit_bytes_n:
                or      a
                ret     z
                ld      b, a
emit_bytes_n_loop:
                ld      a, (hl)
                push    hl
                push    bc
                call    emit_byte
                pop     bc
                pop     hl
                inc     hl
                djnz    emit_bytes_n_loop
                ret
```

### Task 5: Boot self-test for paged emit

**Files:**
- Create: `src/m3/test_emit_paged.asm`
- Modify: `src/m3/assembler.asm` (wire up the new test in the `BUILD_TESTS` block)

- [ ] **Step 1: Write the test file**

Mirror the existing pattern in `src/m3/test_trampoline.asm`. Goal: verify (a) emit writes land in page 5 via section B, (b) zone transition flips `OUT_ZONE` and resets `OUT_PC`, (c) high-zone writes land in page 6.

```
; test_emit_paged.asm — boot-time self-tests for paged emit.
;
; Per docs/plans/2026-05-27-m6-paged-out.md Task 5.
;
; Coverage:
;   1. reset_out_buffer sets OUT_PC = &4000, OUT_ZONE = 0, OUT_LEN = 0.
;   2. emit_byte in low zone writes to section B (= page 5).
;   3. emit_byte 16384 times triggers the zone transition; OUT_ZONE becomes 1,
;      OUT_PC resets to &4000.
;   4. emit_byte in high zone writes to page 6 (verify via LMPR=&25 read-back).

run_emit_paged_self_tests:
                call    reset_out_buffer

; --- (1) initial state ---
                ld      a, (OUT_ZONE)
                or      a
                jp      nz, fail
                ld      hl, (OUT_PC)
                ld      a, h
                cp      &40
                jp      nz, fail
                ld      a, l
                or      a
                jp      nz, fail
                ld      hl, (OUT_LEN)
                ld      a, h
                or      l
                jp      nz, fail

; --- (2) low-zone emit lands in page 5 via section B ---
                ld      a, &AB
                call    emit_byte
                ld      a, &CD
                call    emit_byte
                ld      hl, &4000
                ld      a, (hl)
                cp      &AB
                jp      nz, fail
                inc     hl
                ld      a, (hl)
                cp      &CD
                jp      nz, fail
                ld      hl, (OUT_LEN)
                ld      a, h
                or      a
                jp      nz, fail
                ld      a, l
                cp      2
                jp      nz, fail

; --- (3) force zone transition by emitting until OUT_PC wraps ---
; Fast-forward by setting OUT_PC = &7FFF + 1 - 1 = &7FFF directly (skip the
; 16k loop) but verify the wrap on the NEXT real emit.  Setting OUT_LEN
; too so it remains consistent.
                ld      hl, &7FFF
                ld      (OUT_PC), hl
                ld      hl, 16383
                ld      (OUT_LEN), hl

                ld      a, &EE
                call    emit_byte       ; writes &EE at &7FFF (last byte of low zone),
                                        ; OUT_PC advances to &8000, triggers wrap.

                ld      a, (OUT_ZONE)
                cp      1
                jp      nz, fail
                ld      hl, (OUT_PC)
                ld      a, h
                cp      &40
                jp      nz, fail
                ld      a, l
                or      a
                jp      nz, fail

; --- (4) high-zone emit lands in page 6 ---
                ld      a, &7B
                call    emit_byte
                ld      a, &91
                call    emit_byte

; Read back via LMPR=&25 (page 6 in section B).
                in      a, (251)
                ld      (lmpr_save_test), a
                ld      a, LMPR_OUT_HIGH
                out     (251), a

                ld      hl, &4000
                ld      a, (hl)
                cp      &7B
                jp      nz, fail
                inc     hl
                ld      a, (hl)
                cp      &91
                jp      nz, fail

                ld      a, (lmpr_save_test)
                out     (251), a

                ret

lmpr_save_test: defb    0
```

The test uses one scratch byte `lmpr_save_test` to bracket its own LMPR read-back. Free-standing; no shared state required.
